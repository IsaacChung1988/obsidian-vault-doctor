# Obsidian 知识库管理员（Obsidian Vault Administrator）

面向**已经有库、想把库治好**的 Obsidian 用户：只读体检 → 分级行动方案 → 安全整理 → 可一键回滚。

## 类型

Agent 型（单个 AI 专家）

## 它解决什么问题

| 你的处境 | 它做的事 |
|---|---|
| 库用了半年以上，感觉乱、找不到东西 | 体检 + 健康分，告诉你**先修哪个** |
| 链接点开是空的 | 找断链，**分得清**模板占位符和真断链 |
| 搜到两篇几乎一样的笔记 | 相似度分档列出，只列不删 |
| 不敢动目录（怕链接全断） | 移动/改名自动重写全库链接，改动前自动备份 |
| 改完后悔了 | 按 change-log 逆序回滚，恢复到改动前 |

## 挂载技能（需单独安装）

- **obsidian-vault-engine**（引擎）：scan / health / dup / move / verify / restore / vault 七个脚本，纯 Python 标准库零依赖
- **obsidian-restructure-planner**（规划器）：plan.py 把散点问题排成 A/B/C 三级行动清单 + 健康分

两个 skill 均在**用户本机**运行，笔记内容不出用户电脑。

## 分级逻辑（核心设计）

- **A 级 · 立刻能修**：有唯一正确答案的问题（系统垃圾文件、完全重复、真断链）
- **B 级 · 要你判断**：没有标准答案的事（相似笔记合并、孤儿笔记去向、目录拆分）——只出提案，绝不替你决定
- **C 级 · 别动**：模板占位符、日记无回链、归档快照——这些是正常现象，不是问题

## 红线

- 绝不删除用户文件；唯一允许的"删除"是移入库内 `.trash/`，且可回滚
- 不碰 `.obsidian/`、`.trash/`、`.git/`
- 不承诺"全自动整理"：最多 A 级自动 + B 级出提案
- 健康分只能对比自己治理前后，不能和别人比

## 使用示例

- 帮我体检这个 Obsidian 笔记库，告诉我先修什么
- 我的笔记库几百篇了，找不到东西，该从哪下手
- 帮我整理一个目录并自动更新全库链接，要能反悔

## 隐私与依赖

- 脚本在本机 Python 标准库上运行，**零第三方依赖**，不需要 `pip install`
- 扫描的是你自己的库，笔记内容不上传、不回传

## 安装

1. 安装两个 skill：`obsidian-vault-engine`、`obsidian-restructure-planner`
2. 将本专家包放到专家目录并注册后，在对话中直接说"帮我体检这个 Obsidian 笔记库"
